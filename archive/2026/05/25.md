## May 25, 2026

Two releases stand out this Sunday. Ollama 0.24 brings the Codex desktop app to local inference, adding parallel coding threads and a reworked MLX sampler for Apple Silicon users who want to stay off the cloud. On the eval side, a new study shows LLM coding agents drop roughly 30 points when backend constraints stack up together, a useful reminder before you hand an agent an opinionated framework and an ORM at the same time. Both findings have direct implications for how you scope and test agent workflows in production.

### [coding_agent] [Ollama 0.24 Brings the Codex Desktop App to Local Inference](https://wwwatch.dev/journal/2026-05-25/ollama-0-24-codex-app-local-desktop-coding-agent)

Ollama 0.24 ships built-in support for the Codex App, giving developers a local desktop environment for parallel coding threads, built-in browser annotation, and inline code review. A reworked MLX sampler also improves generation quality on Apple Silicon.

### [eval] [LLM Agents Lose 30 Points When Backend Constraints Stack Up](https://wwwatch.dev/journal/2026-05-25/constraint-decay-llm-agents-backend-code-generation)

A new study finds that LLM coding agents degrade sharply as structural constraints accumulate in backend code generation tasks. Agents that perform well under loose specs often collapse when architecture, ORM, and framework conventions all apply at once.

### [coding_agent] [Your AI Agent Is Not Your Architect. Treat It That Way.](https://wwwatch.dev/journal/2026-05-25/ai-coding-agents-make-bad-architects-heres-why)

AI agents like Claude are confidently agreeable, which makes them dangerous in architectural roles. A consultant's field report explains what goes wrong and who ends up holding the bag.

### [eval] [OpenCompass 0.5.2 Adds Fourteen Benchmarks for Scientific AI Evaluation](https://wwwatch.dev/journal/2026-05-25/opencompass-052-fourteen-new-benchmarks-sci-eval)

OpenCompass 0.5.2 ships fourteen new benchmarks spanning science, biology, chemistry, and instruction-following, plus new model and API support. Here is what product engineers need to know to put it to work today.

### [ops] [Dify Patches Tenant Isolation, Workflow Tracing, and RAG Stability](https://wwwatch.dev/journal/2026-05-25/dify-v1-14-2-security-workflow-reliability-fixes)

Dify v1.14.2 tightens tenant-scoped security, restores workflow tracing after human-in-the-loop resume, and fixes a cluster of knowledge-base and RAG reliability bugs. Here is what changed and what it means for teams running Dify in production.

### [framework] [Transformers v5.9.0 Brings Three New Models and One Breaking Change](https://wwwatch.dev/journal/2026-05-25/transformers-v590-new-models-breaking-audio-changes)

Hugging Face Transformers v5.9.0 adds Cohere2Moe, Parakeet TDT, and HRM-Text to the library while breaking SAM3 and EdgeTAM input contracts. Audio support also gets a notable expansion.
