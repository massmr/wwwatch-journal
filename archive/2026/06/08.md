## June 8, 2026

Two highlights worth your attention today. AnythingLLM v1.13.0 ships Model Router, a rule-based system that silently routes each message to either a local or cloud model depending on conditions you define. It is the first open-source tool to make hybrid routing invisible to end users. Separately, Unsloth Studio adds MCP tool integration and local support for Gemma 4 12B on 8GB RAM, bringing fine-tuning workflows and tool use closer together without a cloud dependency.
